# DSN-009 — ماتریس حالت‌ها/خطاها/گیت‌ها در سطح UI

- هدف: هر حالت هر ماشین (TRD-003 حمل، FIN-002 پول، CMP-002 گیت، SUP-001 احراز، moderation) → نمایش UI، پیام، اقدام مجاز، اعلان (X01) — مرجع واحد پیاده‌سازی (ENG-001) و تست (UX-001)

## ۱) ماتریس حالت حمل (TRD-003 — ۱۳+۵) × نمایش

| حالت | نمایش خریدار (B05/X03) | نمایش فروشنده (S06) | پیام استثنا/اقدام |
|---|---|---|---|
| accepted/drafting/producing/… | تایم‌لاین گام فعال | همان + اقدام بعدی | — |
| customs_hold (مبدأ/مقصد) | هشدار زرد: «توقف گمرکی — در بررسی» + پیگیری CS | اقدام: رفع نقص اسناد | پیام هرگز مبهم نیست (TRD-004) |
| docs_rejected | هشدار: سند رد + کدام | آپلود مجدد | اتصال B06 |
| damaged | قرمز + مسیر ادعا B07 | بیمه INS-001 + مستندات | INS-001 ادعا |
| delayed | برچسب بدون وعده زمان (درس TRD-004) | هم‌سان | — |
| compliance_hold | قفل اقدامات + دلیل عمومی CMP | همان + رفع مورد | CMP-002 |

## ۲) ماتریس حالت پول (FIN-002 — ۱۰ حالت) × نمایش

| حالت | نمایش | اقدام |
|---|---|---|
| payment_pending | دکمه پرداخت/راهنمای روش | انتخاب FIN-001 |
| payment_compliance_hold | قفل + دلیل عمومی | انتظار CMP |
| funds_paid_non_escrow | رسید ثبت‌شده | — |
| funds_held | نزد نگهدارنده مجاز — شرط آزادسازی قابل‌مشاهده | — |
| release_pending_inspection | شمارش پنجره بازرسی | تأیید/ادعا |
| released | رسید + LedgerEvent | امتیازدهی |
| dispute_open→refund_pending/refunded | مسیر حکم | LEG-002/TNS-001 |
| partially_released | تفکیک مراحل | — |

## ۳) ماتریس گیت CMP (CMP-002) × UI

| نتیجه گیت | UI | نمونه پیام (X02) |
|---|---|---|
| pass | عادی | — |
| hold | قفل اقدام + زرد | «در بررسی انطباق…» + مورد رفع |
| reject | قرمز + عدم نمایش عمومی | دلیل قطعی + مسیر اعتراض |
| escalate | خاکستری «در بررسی تخصصی» | بدون SLA قطعی |
| freeze (مقصدی) | همه سفارش‌های مقصد | «تغییر وضعیت مقصد — در بازنگری» |

- مقصد امارات: P05/P08/P12 → غیرفعال + X02 پیام مسدود (TRD-006)

## ۴) ماتریس احراز (SUP-001/A03) و moderation (O02)

| حالت | نمایش فروشنده | اعلان |
|---|---|---|
| kyc_submitted | «در بررسی» + چک‌لیست | — |
| kyc_approved | باز شدن S01..S09 کامل | X01 |
| kyc_rejected | دلیل + resubmit | X01 |
| moderation_approved/rejected | S03 با دلیل | X01 |
| certificate_expired | کالاهای مرتبط «مشروط» + هشدار S01/S07 | X01 |

## ۵) قواعد سراسری UI (DES-001/UX-001)

- هر حالت غیرعادی: سه‌لایه (چه شد/چرا/چه کنم)؛ هیچ بن‌بست بی‌اقدام؛
- دو تایم‌لاین (حمل/پول) همیشه در B05/S06 با یک منبع حقیقت؛
- هر تغییر حالت = اعلان X01 + رکورد audit (SEC-001)؛
- برچسب‌های گیت بدون جزئیات محرمانه CMP؛ حکم حقوقی هرگز در UI داده نمی‌شود (LEG-001).

## پذیرش ماتریس

هر سلول بالا در تست UX-001 (سناریوی گیت) و تست ENG-001 (state machine) پوشش داده می‌شود؛ هیچ حالتی بدون پیام/اقدام تعریف‌نشده باقی نمی‌ماند.
