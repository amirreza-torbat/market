# DSN-008 — صفحات سیستم + فلوهای بین‌صفحه‌ای (X01–X03)

---

## X01 — مرکز اعلان‌ها و قالب‌ها

- هدف: هر رویداد ماشین‌های وضعیت → اعلان درست به طرف درست در کانال درست
- بلوک‌ها: (1) مرکز اعلان درون‌پنلی (B01/S01) با خوانده/نخوانده؛ (2) کاتالوگ قالب اعلان به‌تفکیک رویداد — هر قالب: رویداد (DATA-001)، گیرنده، کانال (درون‌پنل/ایمیل)، زبان‌ها (LOC-001)؛ (3) رضایت‌های اعلان بازاریابی جدا (LEG-004)
- کاتالوگ رویداد→اعلان (از FIN-002/TRD-003/CMP-002/TNS-001):
  - `compliance_hold ON/OFF` → خریدار+فروشنده (دلیل عمومی — CMP-002)
  - `quote_received` → خریدار (با مهلت اعتبار quote)
  - `rfq_timeout` → فروشنده (CS-001 یادآور)
  - `moderation_rejected` → فروشنده (دلیل + اصلاح)
  - `certificate_expiring` → فروشنده (S07 هشدار)
  - `psi_report_issued` → دو طرف (INSP-001)
  - `shipment_state_changed` → دو طرف (TRD-003)
  - `funds_released / refund_issued` → دو طرف (FIN-002)
  - `dispute_stage_changed` → دو طرف (TNS-001)
  - `destination_gate_changed` → همه سفارش‌های متأثر (TRD-013 T14 — الگوی freeze&review CMP-002)
- داده: Notification[] + Event (DATA-001)
- وضعیت‌ها: شکست ارسال ایمیل → retry + درون‌پنلی همیشه موجود
- شواهد: DATA-001؛ FIN-002/003؛ CMP-002؛ TNS-001؛ LEG-004 | پذیرش: هیچ رویداد وضعیت‌سازی بدون اعلان نماند؛ اعلان‌های انطباق همیشه درون‌پنلی هم باشند

## X02 — صفحات حالت‌ها (خطا/خالی/گیت مسدود)

- هدف: استاندارد پیام‌های سیستم — سه‌لایه (چه شد/چرا/چه کنم — DES-001)
- بلوک‌ها/الگوها:
  - **گیت مسدود (امارات — TRD-006):** «سفارش به این مقصد فعلاً امکان‌پذیر نیست. وضعیت: تعلیق تجاری از [تاریخ]. این تصمیم مطابق سیاست انطباق ماست. [وضعیت را پیگیری کنید→P12]» — بدون جزئیات حقوقی، بدون استثنا
  - **compliance_hold:** «سفارش شما در بررسی انطباق است. تا تعیین تکلیف، ارسال/پرداخت متوقف است. [پیگیری→B05]»
  - **permit_pending:** «کالای شما به مجوز X نیاز دارد [TRD-005]. [راهنمای اسناد→P12/P14]»
  - 404 / 500 / خطای پرداخت / سشن منقضی / آپلود ناموفق / نتیجه خالی جست‌وجو
- قاعده: هیچ پیام خطایی دلیل فنی داخلی لو نمی‌دهد؛ هر خطای گیت مسیر رفع/پیگیری دارد؛ همه زبان‌ها (LOC-001)
- شواهد: DES-001 (خطاها)؛ CMP-002؛ TRD-006؛ TRD-013 | پذیرش: هیچ گیت مسدودی پیام مبهم ندارد؛ هیچ خطایی بن‌بست نیست

## X03 — رهگیری عمومی سفارش (مهمان)

- بلوک‌ها: ورود کد رهگیری (سفارش یا استعلام مهمان) + نمایش وضعیت محدود: حالت حمل فعلی (TRD-003)، وضعیت پول (فقط برچسب عمومی FIN-002)، اسناد عمومی؛ بدون داده طرفین (LEGAL-004 حداقل‌سازی)
- داده: Order/RFQ (با guest_code)
- وضعیت‌ها: کد نامعتبر → پیام صریح؛ سفارش محرمانه (درخواست خریدار) → رهگیری عمومی غیرفعال
- فلو: P09→X03؛ پنل‌ها جایگزین کامل‌ترند
- شواهد: P09؛ TRD-003؛ FIN-002؛ LEG-004 | پذیرش: پیگیری مهمان بدون فاش‌کردن داده طرفین

## فلوهای بین‌صفحه‌ای (Cross-page flows — نقشه کامل)

### F1 — استعلام تا PO (خریدار جدید)
P01/P04 → P05 → P08 (گام‌های ۱–۴، مهمان) → P09 (کد) → A01 (ثبت سبک، اتصال RFQ) → B03 (مقایسه) → A01-جست‌وجوی سند خریدار در صورت PO → B03 → PO → B04/B05 (گیت CMP در مسیر)

### F2 — سفارش تا آزادسازی (خریدار+فروشنده)
B03 (انتخاب quote) → CMP-002 → B04/B05 (payment_secured → funds_held) → S06 (تولید S02/S04 پیش‌زمینه) → S08 (PSI) → B05 (گزارش) → S06 (ارسال/LOG-001) → B05 (رهگیری) → تحویل → پنجره پذیرش → FIN-002 released → B05/S06 اعلان → B07 در صورت ادعا

### F3 — ورود فروشنده تا اولین لید
A01 (فروشنده) → A03 (KYC — CMP-001) → S02 (پروفایل) → S04 (کالا) → O02 (moderation) → P05 عمومی → S05 (RFQ ورودی) → quote → RND-SELL-001 گام ۱۰–۱۶

### F4 — تغییر وضعیت گیت مقصد ( freeze&review — CMP-002)
O01/منبع خبری → تغییر DestinationRule (O06/MGT) → freeze سفارش‌های متأثر → اعلان X01 به همه → بازبینی O01 → آزادی/تداوم hold (الگوی امارات — TRD-006 T14)

### F5 — اختلاف تا اجرا
B05/B07 (ادعا) → O03 (مستندات دوطرفه + INSP) → حکم → FIN-002 (refund/release) → B05/S06 → امتیاز TNS-001

### F6 — انقضای گواهی (فروشنده)
S07 هشدار → انقضا → کالاهای مرتبط «مشروط» خودکار → S01 هشدار → اصلاح → بازگشت به live
