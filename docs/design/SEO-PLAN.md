# SEO-PLAN — تسک‌بندی کامل سئو با دستورات اجرایی (طبق AMEND-001 اصلاح ۴)

- ورودی: SEO-001، LOC-001، RND-009 (ضدالگوها)، AMEND-001 (اصلاح ۱–۳)
- زبان‌های لانچ: fa، en، ar (فاز ۱) → ru، tr، zh (فاز ۲) — هر زبان مجموعه صفحات مستقل ایندکس‌شونده
- قاعده مادر: هر تسک زیر «تعریف انجام‌شده» و «معیار پذیرش» دارد؛ اجرا در milestoneهای BUILD-PLAN

## SEO-B-001 — زیرساخت فنی سئو [P0 | M2]
دستور: SSR برای همه صفحات عمومی؛ robots.txt (پنل‌ها noindex، عمومی Allow)؛ `sitemap-{lang}.xml` برای هر زبان + sitemap index؛ canonical درست هر URL؛ ساختار URL: `/{lang}/...` (بدون پارامتر در URL محتوایی)؛ 404 واقعی برای محتوای ناموجود؛ ریدایرکت‌های 301 (نه JS).
پذیرش: هر صفحه عمومی با view-source قابل خواندن بدون JS؛ هر URL یک canonical یکتا؛ sitemapها معتبر و به‌روز خودکار.

## SEO-B-002 — مجموعه صفحات مستقل هر زبان [P0 | M2] (اصلاح ۱)
دستور: مسیرهای `/{lang}/` برای fa/en/ar (فاز ۱)؛ هر صفحه در هر زبان نسخه مستقل با محتوای بومی‌شده؛ `hreflang` کامل (ماتریس زبان‌ها + x-default=en)؛ صفحات کلیدی ترجمه انسانی/بومی‌شده (LOC-001)؛ عنوان/توضیحات به‌تفکیک زبان.
پذیرش: برای هر زبان نمونه، خروجی `site:example.com/{lang}/` مستقل؛ hreflang بدون خطا (تست ابزار)؛ محتوای هر نسخه بومی‌شده نه ماشینی.

## SEO-B-003 — مواجهه جغرافیایی زبان [P0 | M2] (اصلاح ۲)
دستور: middleware edge: بازدید اول → تشخیص کشور (GeoIP) + Accept-Language → ریدایرکت 302 به `/{lang}/` + کوکی `lang_pref` (۱ سال)؛ بازدیدهای بعدی → کوکی حاکم؛ **خزنده‌ها هرگز ریدایرکت نمی‌شوند** (UA detect: Googlebot/Bingbot → 200 مستقیم)؛ سوییچر دستی → کوکی override؛ بدون cloaking (محتوای هر URL برای همه یکسان).
پذیرش: کاربر ایران → /fa؛ عراق → /ar؛ آلمان → /en؛ Googlebot → همیشه محتوای مستقیم URL؛ سوییچ دستی پابرجا.

## SEO-B-004 — اسکرول بی‌پایان خزپذیر [P0 | M2] (اصلاح ۳)
دستور: UX = infinite scroll با IntersectionObserver؛ زیرساخت = API cursor-based بدون سقف؛ برای خزنده: لینک‌های واقعی `?page=N` در DOM (progressive enhancement) + pushState همگام اسکرول؛ دکمه «مشاهده به‌صورت صفحه‌بندی‌شده» مخفی برای دسترسی؛ صفحات `?page=N` با canonical خود به نسخه شماره ۱ (یا self — تصمیم: self برای هر صفحه ایندکس‌پذیر نگه‌داشتن عمق) — اجرا: هر دو الگو در QA کنترل شود.
پذیرش: خزنده بدون JS می‌تواند به عمق ۱۰۰+ آیتم برسد از طریق لینک‌ها؛ کاربر اسکرول بی‌پایان دارد؛ هیچ سقف سروری در کوئری نیست (cursor).

## SEO-B-005 — داده ساختاریافته [P0 | M3]
دستور: JSON-LD: Product+Offer+AggregateRating (P05)، Organization (P07)، BreadcrumbList (همه)، FAQPage (P14)، ItemList (P03/P04/P06)، Article (P15)؛ اعتبارسنجی Rich Results.
پذیرش: صفر خطای Rich Results Test روی نمونه هر نوع.

## SEO-B-006 — استراتژی محتوا [P1 | M3-M8]
دستور: سه خانواده محتوای یونیک: (الف) صفحات دایرکتوری «تولیدکننده ایرانی در {شهر/صنعت}» (الگوی IndiaMART — RND-005 D55)؛ (ب) راهنماهای مقصد از TRD-006..012 (P12 — محتوای یونیک که رقبا ندارند: گیت انطباق)؛ (ج) بینش‌ها (P15) از خلاصه عمومی‌شده پرونده‌ها. تقویم محتوا: ۲ مقاله/هفته فاز اول.
پذیرش: هر صفحه محتوای یونیک با نویسنده/تاریخ؛ هیچ محتوای کپی از رقبا (ضدالگوی RND-009).

## SEO-B-007 — قواعد On-page [P0 | M2]
دستور: title یکتا ≤۶۰ کاراکتر + الگو «{کالا} | تولیدکننده ایرانی — {برند}»؛ meta description یکتا؛ H1 یکتا؛ سلسله‌مراتب H2/H3؛ alt توصیفی تصاویر؛ slug تمیز (ضدالگوی عنوان کلمه‌کلیدمحور RND-003 D71-2)؛ لینک‌سازی داخلی: هر کالا→دسته/پروفایل/راهنمای مقصد.
پذیرش: صفر عنوان تکراری در crawl؛ هر تصویر alt دارد.

## SEO-B-008 — Core Web Vitals [P0 | M3+M9]
دستور: بودجه عملکرد: LCP<2.5s، CLS<0.1، INP<200ms؛ بهینه‌سازی تصویر (WebP/AVIF lazy)، code-splitting، کش CDN/edge؛ پایش Lighthouse CI در هر release.
پذیرش: Lighthouse SEO+Perf ≥۹۰ روی نمونه صفحات P0.

## SEO-B-009 — پایش و ابزار [P1 | M3]
دستور: Google Search Console + Bing Webmaster به‌تفکیک property زبانی؛ مانیتور ایندکس/خطا/sitemap؛ لاگ جست‌وجو؛ هشدار افت ایندکس؛ بررسی دوره‌ای hreflang.
پذیرش: هر ۶ property (زبان‌ها) متصل؛ هشدارها به تیم می‌رسد.

## SEO-B-010 — چک‌لیست QA سئو پیش از هر لانچ [P0 | M9]
دستور: چک‌لیست ۲۰ بندی: robots/canonical/hreflang/sitemap/عنوان‌ها/alt/structured data/CWV/صفحه‌بندی خزپذیر/redirectها/404/محتوای یونیک/تاریخ‌ها/زبان‌ها/دایرکتوری‌ها/راهنمای مقصد/وبلاگ/GSC/سرعت/ضدالگوهای RND-009 — امضای QA پیش از release.
پذیرش: هر release بدون امضای چک‌لیست سئو منتشر نمی‌شود.
