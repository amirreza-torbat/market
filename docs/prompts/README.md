# کتابخانه پرامپت‌های اجرایی

این پوشه شامل هویت تخصصی ایجنت‌ها، پرامپت راه‌اندازی Git و پرامپت مستقل هر تسک برنامه تحقیق است.

برای راه‌اندازی دسترسی Git، ابتدا [`02-BOOTSTRAP-AGENT.md`](02-BOOTSTRAP-AGENT.md) را ارسال کن. برای دریافت خروجی قابل اتکا، همیشه این سه فایل را به ایجنت بده:

1. [`01-AGENT-IDENTITY.md`](01-AGENT-IDENTITY.md) — هویت مشترک و رفتار سازمانی
2. فایل هویت واحد از [`identities/`](identities/) — نقش، مأموریت و حدود اختیار
3. [`00-GLOBAL-PROTOCOL.md`](00-GLOBAL-PROTOCOL.md) و فایل تسک مربوطه از [`tasks/`](tasks/)

## ترتیب پیشنهادی ابلاغ

`RND-001` → `RND-002` → پرونده‌های Tier A → `RND-SELL-001` و `RND-BUY-001` → `TRD-005` و سایر تحلیل‌های تخصصی → `PM-001` → `ENG-001` → `SYN-001`.

`MGT` باید وابستگی‌های CSV را رعایت کند و هر بار فقط یک تسک را ابلاغ کند. فایل‌های مربوط به حقوق، پرداخت، تحریم و آمار صادرات باید مستقل و با منابع رسمی بازبینی شوند.

## نکته مهم درباره آمار صادرات

پرامپت [`TRD-005.md`](tasks/TRD-005.md) صراحتاً استخراج پنج‌ساله را برای هر **کد تعرفه × کشور مقصد** از منبع رسمی گمرک ایران می‌خواهد. خروجی عددی بدون URL، نام جدول، تاریخ دسترسی، واحد، روش محاسبه و کنترل جمع، قابل پذیرش نیست.
