## ۲) ارتقا (Escalation — پله‌ای)

```
لایه ۱: CS/عملیات (SLA — CS-001) → لایه ۲: کارشناس واحد مالک
→ لایه ۳: سرپرست واحد + CMP/LEG (در صورت پرچم) → لایه ۴: صاحب‌کار/MGT
```
- هر ارتقا: رکورد، دلیل، مهلت؛ حوادث تحریمی/داده‌ای: اطلاع فوری CMP/LEG (SEC-001 §5)؛
- ماتریس «چه چیزی به کی»: escalation matrix وصل به نقش‌های SEC-001 و مالکان بالا.

## ۳) تداوم (Continuity)

- RPO/RTO پیشنهادی: داده مالی = صفر فقدان (append-only — FIN-003)؛ پنل = RTO کوتاه (`پارامتر`)؛
- سناریوها: قطعی شریک پرداخت/نگهدارنده، بلاک شدن مسیر بانکی (TRD-010/011 محیط)، حمله، حادثه داده؛
- پشتیبان‌گیری: مالی/اسناد هر روز + خارج از مکان (LEG-004 انتقال حداقلی)؛
- جایگزین فرایند دستی موقت با ثبت کامل (نه دورزدن گیت‌ها — CMP-002).

## ۴) تأمین‌کنندگان (Vendor playbook)

| گروه | نمونه | الزام |
|---|---|---|
| مالی/نگهدارنده وجوه | بانک/شریک escrow | مجوز + قرارداد (LEG-001/002) + گیت CMP |
| بازرسی | INSP شرکا | گزارش سریال‌دار (INSP-001) |
| ابر/زیرساخت | میزبانی | فیلتر CMP (ترسیم تحریم) + LEG-004 انتقال داده |
| حمل | کارگزار | صلاحیت (LOG-001) + CMP-001 گروه د |

- هر vendor: مالک رابطه، قرارداد، بررسی دوره‌ای، خروج برنامه‌دار (exit plan) — `عرف حاکمیتی`.

## ۵) حسابرسی (Audit)

- audit trail غیرقابل حذف (SEC-001 §4) + گزارش‌های دوره‌ای: مالی (FIN-003)، انطباق (CMP)، SLA (CS-001)، حوادث (SEC)؛
- بازبینی سالانه سیاست‌ها + پس از هر حادثه/تغییر بزرگ (SYN-001 تصمیم‌ها نسخه‌دار).
