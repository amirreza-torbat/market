## ۲) قیف جذب و KYB خریدار

```
آگاهی (SEO/محتوا) → ثبت سبک (الگوی مهمان‌پذیر — RND-008 یافته ۴)
→ KYB حداقلی (ثبت شرکت/IEC-معادل مقصد — TRD-008 T01) → غربال CMP-001
→ خریدار فعال → سفارش آزمایشی (الگوی BUY-001 نقشه مادر) → تکرار
```
- اصل: KYB سنگین فقط در نقطه سفارش/پرداخت، نه زودهنگام (ضدالگوی دیوار لاگین زودهنگام — RND-008 یافته ۴).
- `نیازمند وکیل`: الزامات KYB به‌تفکیک مقصد.
