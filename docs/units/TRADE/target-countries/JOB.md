# زیرواحد `TRADE/CTY` — شرایط کشورهای هدف

کد `MKT` برای بازاریابی برند است. اینجا قاطی نکنید.

## مأموریت

برای هر کشور هدف یک پرونده زنده: تعرفه، استاندارد وارداتی، حساسیت مبدأ ایران، زبان اسناد، بندر رایج، ریسک رد محموله.

## موج اول کشورها (تا MGT عوض کند)

امارات، عراق، ترکیه، عمان، روسیه، هند، چین.

هر کشور یک تسک جدا بعد از خط پایه ایران.

## نمی‌کند

کمپین بازاریابی جذب تاجر (`BUY`/`MKT` برند).
