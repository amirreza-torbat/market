# زیرواحد `TRADE/DOC` — چرخه اسنادی معامله

## مأموریت

ترتیب واقعی اسناد از پیش‌فاکتور تا تسویه و ترخیص مقصد را بنویسد و به وضعیت سفارش محصول وصل کند.

## وظایف

- پروفرما → تأیید → اینویس → پکینگ → بازرسی → بارنامه → گواهی مبدأ → بیمه → اظهار
- تفاوت مسیر TT با LC از نظر سند (با ارجاع به `FIN` نه تصمیم مالی)
- چه سندی شرط آزادسازی وجه است (پیشنهاد به `FIN`/`LEG`)
