# داده‌های TRD-001

- `TRD-001-document-lifecycle-raw.csv`: رکوردهای خام چرخه سند، بدون محاسبه عددی.
- `TRD-001-document-lifecycle-processed.csv`: همان رکوردها با نوع صادرکننده، مشروط‌بودن و gate وضعیت سفارش نرمال‌شده برای مصرف محصول.
- همه وضعیت‌های سفارش در این فایل‌ها `پیشنهاد-محصول` هستند و وضعیت رسمی گمرک، بانک یا carrier نیستند.
- برای الزام `required/conditional`، منبع و کشور/کالا باید به rule version جداگانه متصل شود؛ هیچ مقدار ناشناخته‌ای به `not_required` تبدیل نشده است.
- محاسبه آماری یا گردکردن انجام نشده است؛ نسبت نمونه کنترل‌شده در گزارش با فرمول ثبت شده است.
- تاریخ دسترسی منابع: 2026-08-24 UTC.
