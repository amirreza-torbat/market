# TRD-014 — چک‌لیست فیلد ثبت کالا در پلتفرم (خروجی TRADE)

- واحد: `TRADE/CUS` | تسک: `TRD-014` | تاریخ: 2026-09-27
- وضعیت گزارش: review (آماده QA)
- ورودی: TRD-004 (اطهار EPL و فیلدها)، TRD-005 (شناسه مجوز + T14)، TRD-013 (متادیتای مقصد پارامتری)، TRD-003 (وضعیت‌های حمل)، TRD-007..012 (گیت‌ها) — همه accepted

### د) فیلدهای اظهار/حمل (پیوند TRD-003/004)

شماره سریال اظهار/کوتاژ؛ مسیر سبز/زرد/قرمز (پیغام گمرک بدون وعده زمان)؛ شماره پروانه سبز الکترونیکی؛ وضعیت سفارش به‌پیوند مدل حمل TRD-003 (declared و…)؛ وضعیت گیت CMP (`compliance_hold`).

## قانون کسب‌وکار تجمیعی (اثر، نه حکم PM)

```
فیلد اجباری خالی → ثبت کالا/سفارش مسدود
مقصد = امارات → غیرقابل انتخاب تا رفع تحریم (TRD-006)
مقصد با گیت → compliance_hold تا تأیید CMP
مقصد-محور نبودن فیلد → چک‌لیست قبل از اعزام با هشدار (نه مسدودی)
محرک بازنگری هر ماتریس (T14 همه پرونده‌ها) → اعلان به‌روزرسانی در پنل
```

## محدودیت‌ها

فیلدهای DES/UX (نمایش) خارج از دامنه TRADE است؛ تصمیم نهایی PM-001/PIM-001. سلول‌های `*` TRD-013 پس از تثبیت رسمی به فیلدها اضافه می‌شوند.

## HANDOFF
