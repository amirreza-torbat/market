# شیوه کار `TRADE`

## توالی دانش

1. نقشه دامنه و منابع معتبر
2. خط پایه صادرات ایران (مشترک همه کالاها)
3. چرخه اسنادی
4. مجوز وابسته به کالا
5. کشور هدف یکی‌یکی
6. ماتریس `دسته × مقصد × سند`
7. چک‌لیست فیلد محصول

کشور دوم را قبل از تمام شدن کشور اول شروع نکنید.

## منبع معتبر

اولویت منبع:

1. متن قانون / بخشنامه / سایت گمرک ج.ا.ا / سازمان توسعه تجارت / اتاق بازرگانی / INSO
2. راهنمای گمرک کشور مقصد
3. منبع حرفه‌ای فورواردر با تاریخ
4. مقاله تجاری — فقط مکمل، نه تک‌منبع بند اجباری

تاریخ مشاهده و نسخه بخشنامه را بنویسید. قانون بدون تاریخ = نقص `C-SOURCE`.

## برچسب

- `واقعیت-قانون:` ماده یا صفحه رسمی
- `عرف-تجاری:` رویه رایج بدون الزام قانونی قطعی
- `فرض:`
- `اثر-محصول:`

هرگز عرف را به‌جای قانون جا نزنید.

## برای ایجنت بعدی

همان بلوک اجباری RND. به‌علاوه: «کدام HS یا کدام کشور را دیگر از صفر نقشه نکن».
