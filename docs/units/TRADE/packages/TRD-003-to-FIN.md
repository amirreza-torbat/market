## گره وضعیت حمل به ماشین وضعیت پول (پیشنهاد — حکم نهایی FIN)

| حالت حمل | ماشه پولی پیشنهادی |
| --- | --- |
| `accepted` | اتصال escrow/پیش‌پرداخت طبق قواعد FIN |
| `producing` / `sample` | پرداخت‌های مایل‌استون تولید (قراردادی) |
| `permit_pending` | هیچ پرداخت مرحله‌ای مشروط به مجوز آزاد نشود |
| `docs_prep` | هزینه‌های اسناد/حمل داخلی از حساب عملیات |
| `declared` | پرداخت هزینه‌های گمرکی مبدأ |
| `origin_loaded` | **ماشه اصلی آزادسازی**: B/L on-board + اسناد ارائه‌شده |
| `in_transit` | زیر L/C: پرداخت بانک روی اسناد منطبق (استقلال اعتبار — تفسیر نیازمند وکیل) |
| `arrived` | تسویه‌های مقصد حسب Incoterm (DDP: فروشنده؛ بقیه: خریدار) |
| `در_مقصد` | آزادسازی نهایی escrow پس از POD |

## برگشت/نگه‌داشت (hold) وصل به حالت استثنا

| حالت | اثر پولی پیشنهادی |
| --- | --- |
| `docs_rejected` | توقف آزادسازی تا اصلاح؛ مهلت مشخص + مسیر فسخ قراردادی (تفسیر نیازمند وکیل) |
| `customs_hold` | نگه‌داشت سهم فروشنده تا رفع؛ تمدید مهلت‌ها |
| `damaged` | توقف تا تعیین مسئول (بیمه/متصدی) و نقطه انتقال ریسک |
| `delayed` | جریمه/تنبیه فقط طبق قرارداد — تفسیر نیازمند وکیل |
| `compliance_hold` | انجماد کامل کالا و پول تا رأی CMP/LEG |

## هشدار UCP600
