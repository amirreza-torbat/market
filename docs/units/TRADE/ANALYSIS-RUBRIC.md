# روبریک تحقیق بازرگانی

برای هر موضوع کشور یا کالا، مگر بریف کم کند.

| کد | بُعد |
| --- | --- |
| `T00` | نهاد مسئول و منبع رسمی |
| `T01` | شرط اهلیت صادرکننده (کارت بازرگانی، مجوز موردی) |
| `T02` | کالای آزاد / مشروط / ممنوع |
| `T03` | اسناد پایه مشترک |
| `T04` | اسناد وابسته به کالا |
| `T05` | HS و ریسک طبقه‌بندی |
| `T06` | رویه گمرک ایران گام‌به‌گام |
| `T07` | کشور مقصد: تعرفه و ترجیح |
| `T08` | کشور مقصد: استاندارد و برچسب |
| `T09` | کشور مقصد: محدودیت مبدأ ایران |
| `T10` | گواهی‌های خاص (بهداشت، قرنطینه، حلال، COC) |
| `T11` | Incoterms اثر روی مسئولیت سند |
| `T12` | شکست رایج و پیام محصول |
| `T13` | قانون کسب‌وکار قابل‌پیاده‌سازی |
| `T14` | تاریخ اعتبار و محرک بازنگری |

بخش بدون منبع رسمی برای بند قانونی = خالی.
