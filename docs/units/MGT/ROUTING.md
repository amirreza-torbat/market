# جدول توزیع یافته‌ها — مدیر اجرا می‌کند نه تحلیل

منبع اصلی داده رقبا: `docs/units/RND/packages/`  
منبع اصلی قانون و مقصد: `docs/units/TRADE/packages/`

## از RND به کجا

| اگر بسته درباره این است | مقصد | الان خط باز است؟ |
| --- | --- | --- |
| ترتیب کالبدشکافی، فهرست سایت، پیشنهاد خرد کردن صف | `MGT` (خودت در ACTIVITY و QUEUE) | بله |
| ادعای خدمت گمرک / اسناد / Incoterms روی پلتفرم رقیب | `TRADE` | بله |
| رنگ، تایپ، چیدمان، CTA، موبایل | `DES` | نه → `routed/DES/` |
| درخت دسته، فیلتر، URL، کارت کالا | `PIM` و `SEO` | نه → `routed/PIM/` و `routed/SEO/` |
| نشان اعتماد، امتیاز، تقلب | `TNS` و `SUP` | نه → `routed/TNS/` `routed/SUP/` |
| عضویت پولی، کارمزد، Trade Assurance | `FIN` و `PM` | نه → `routed/FIN/` `routed/PM/` |
| سفر کاربر، RFQ | `PM` و `CS` | نه → `routed/PM/` `routed/CS/` |
| اپ | `MOB` | نه → `routed/MOB/` |

`RND-001` فقط هویت است. انتظار توزیع سنگین UI نداشته باش. حداقل:

- `RND-001-to-MGT` → در صف RND برای خرد کردن `RND-007` استفاده کن
- `RND-001-to-TRADE` → بگذار در `docs/units/TRADE/inbox/PACK-RND-001.md` (خواندنی؛ CURRENT آن‌ها را عوض نکن تا `TRD-001` تمام شود)

## از TRADE به کجا

| بسته | مقصد |
| --- | --- |
| نقشه منابع / پیشنهاد عوض شدن صف | `MGT` |
| «این را با بلاگ رقبا قاطی نکن» | `RND` به‌صورت `PACK-TRD-001` در inbox — CURRENT را عوض نکن |
| بعداً ماتریس اسناد | `PIM` `SUP` `PM` (hold) |
| بعداً فیلد ثبت کالا | `PM` `DES` (hold) |

## قانون تزاحم

اگر `TRADE` وسط `TRD-001` است، بسته RND را در inbox می‌گذاری با پیشوند `PACK-` و در فایل می‌نویسی «بخوان؛ تسک جاری را رها نکن». CURRENT آن‌ها همان `TRD-001` می‌ماند.
