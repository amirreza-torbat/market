# SEO-001 — معماری اطلاعات و بریف سئو بین‌الملل

- واحد: `SEO` | تسک: `SEO-001` | تاریخ: 2026-09-27
- وضعیت گزارش: review (آماده QA)
- معیار پذیرش رجیستری: «URL indexability schema and multilingual content defined»
- ورودی (accepted): RND-005 D55 (الگوی دایرکتوری IndiaMART)، RND-004 D71 (ضدالگوی بلاک ربات)، RND-003 D21/D28 (درخت دسته/URL)، LOC-001 (زبان‌ها)، CAT-001 (دسته‌ها)

## ۱) ایندکس‌پذیری (Indexability)

- `قاعده صریح`: صفحات عمومی (خانه/دسته/پروفایل/کالا) **هرگز برای موتورهای جست‌وجو بلاک نمی‌شوند** — ضدالگوی 403 سراسری Global Sources (RND-004 D71-3)؛ فقط پنل‌ها/داده محرمانه noindex؛
- sitemap.xml زنده + robots.txt صریح + صفحات «X تولیدکننده ایرانی در Y» (الگوی IndiaMART شهر-محور — RND-005 D55)؛
- رندر سمت سرور برای محتوای حیاتی (اسکریپت‌محوری ممنوع برای HTML اصلی — `عرف`).

## ۲) الگوی URL (Schema)

```
/{lang}/categories/{cat}          ← درخت CAT-001
/{lang}/suppliers/{slug}         ← پروفایل
/{lang}/products/{cat}/{slug}    ← PDP (PIM slug)
/{lang}/iran-manufacturers/{city} ← دایرکتوری شهر (الگوی IndiaMART)
hreflang بین نسخه‌های زبانی (FA/EN/AR/RU — LOC-001)
```
- الگو از مشاهده رقبا: `/products-search/...` (MIC — RND-003 D28)، میکروسایت زیردامنه؛ ما: پوشه زبانی + اسلاگ تمیز (ضدالگوی عنوان کلمه‌کلیدمحور — RND-003 D71-2).

## ۳) محتوای چندزبانه

- هر زبان: محتوای بومی‌شده واقعی، نه ترجمه ماشینی صفحات کلیدی (LOC-001 قاعده)؛
- صفحه عمومی هر تأمین‌کننده = «پرونده انطباق عمومی» (RND-007a یافته) → محتوای یونیک قابل ایندکس که هیچ رقیبی ندارد؛
- اسکیما: Organization/Product/Offer/AggregateRating برای کارت‌های غنی (`عرف`).

## ۴) T14

الگوریتم‌های موتورها؛ افزودن زبان؛ تغییر درخت دسته (CAT).
