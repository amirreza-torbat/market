# INSP-001 — ماژول بازرسی (گردش کار بازرسی و اتصال به پرداخت)

- واحد: `INSP` | تسک: `INSP-001` | تاریخ: 2026-09-27
- وضعیت گزارش: review (آماده QA)
- معیار پذیرش رجیستری: «Sampling stages report and payment linkage defined»
- ورودی (accepted): RND-SELL/BUY-001 (مراحل ۱۳/۱۰)، TRD-003 (حالت‌های حمل)، FIN-002 (ماشین پول)، RND-003 D40-41 (الگوی حسابرسی سریال‌دار MIC)

## ۱) مراحل بازرسی (Inspection stages)

| مرحله | چه چیزی | چه کسی | خروجی |
|---|---|---|---|
| پیش‌تولید (Pre-production) | مواد/نمونه اولیه | بازرس ثالث/فروشنده | گزارش اولیه |
| حین تولید (DUPRO) | نمونه‌برداری از خط | بازرس ثالث | گزارش پیشرفت + عکس |
| پیش‌ازحمل (PSI — Pre-Shipment) | نمونه‌برداری نهایی طبق AQL (`عرف صنعتی` — سرنخ) | بازرس ثالث مستقل | **گزارش PSI سریال‌دار** + نتیجه Pass/Fail |
| بارگیری (Loading) | صحت کالا/کانتینر | بازرس/کارگزار | گزارش بارگیری |

## ۲) نمونه‌برداری (Sampling)

- استاندارد AQL (آمارگانه پذیرش — `عرف صنعتی ISO 2859 — سرنخ`)؛ سطح بازرسی و AQL پارامتر قرارداد (LEG-002)؛
- قاعده: نمونه تصادفی توسط بازرس مستقل نه فروشنده؛ عکس/ویدیو الزامی؛
- `اثر-محصول`: فیلد «AQL/سطح بازرسی» در سفارش (TRD-014).

## ۳) گزارش و ردیابی (الگوی سریال‌دار)

- هر گزارش: شماره سریال ردیاب + تاریخ + بخش‌های ثابت (مطابق الگوی گزارش حسابرسی MIC — RND-003 D41: اطلاعات عمومی، ظرفیت، کنترل کیفیت، تصاویر، نتیجه)؛
- وضعیت‌ها: `requested → scheduled → performed → report_issued → pass/fail`؛
- fail → اتصال به `docs_rejected`/رفع نقص (TRD-003 استثناها).

## ۴) اتصال به پرداخت (Payment linkage — FIN-002)

```
پیش‌پرداخت (FIN-002 حالت ۳/۴) → PSI pass → شرط ارسال
PSI fail → توقف ارسال + رفع نقص یا برگشت طبق حکم (حالت ۷-۹ FIN-002)
حمل بدون PSI در سفارش‌های «بازرسی‌الزامی» → مسدود (قاعده CMP-001-گروه د)
```
- بازرسی هزینه مستقل است (FIN-003 خدمت افزودنی)؛ انتخاب بازرس توسط خریدار یا پلتفرم (پارامتر قرارداد).

## ۵) استثناها/ریسک

بازرس دسترس‌ناپذیر → تعویق حمل (LOG)؛ مغایرت نتیجه بازرس با خریدار → escalate/حکم (FIN-002 حالت ۷)؛ ریسک «بازرس دست فروشنده» → فقط بازرس ثالث مستقل با سریال (ضدالگوی اعتماد بی‌سند RND-009).

## T14

تثبیت AQL/نرخ با شرکای بازرسی؛ تغییر استاندارد نمونه‌برداری؛ یافته QA.
