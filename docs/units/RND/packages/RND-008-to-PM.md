# بسته RND-008 به PM (routed)

- از: RND | تاریخ: 2026-09-27 | مرجع: `outbox/RND-008.md`

## ورودی مستقیم PRD (PM-001)

1. گیت انطباق = قابلیت تمایز شماره ۱ (در هیچ‌یک از ۹ رقیب نیست) — در PRD به‌عنوان قید محصول، نه feature اختیاری.
2. مدل درآمد: سه الگو بررسی شد؛ تصمیم PM/FIN با قیمت‌گذاری شفاف (الگوی IndiaMART) و بدون ادعای بی‌سند.
3. لایه اعتماد: هر نشان باید سند روش عمومی داشته باشد (الگوی MIC سریال‌دار؛ TrustSEAL چک‌لیست مدارک).
4. RFQ مهمان‌پذیر (استعلام بدون حساب) به‌عنوان فرضیه تمایز برای تست.
5. چندزبانه EN/AR/RU (+FA) — استاندارد هر دو رقیب ایرانی.

## اثر روی ماژول‌ها (ENG-001)

- وضعیت `compliance_hold` (TRD-007) + پرونده انطباق تأمین‌کننده + فیلد مجوز (TRD-005) → ماژول انطباق عرضی.
