## سفر خریدار/فروشنده قابل‌اندازه‌گیری

- مهمان: مرور + دیدن قیمت US$ بدون حساب ✓؛ تماس/سفارش بدون حساب: مشاهده نشد (دیوار لاگین رندر نشد).
- RFQ «Easy Sourcing»: ۴ گام اعلامی، «1 request, multiple quotes»، مقایسه پیشنهادها + درخواست نمونه؛ فرم: مشاهده نشد.
- Inquiry Basket برای مقایسه چند تأمین‌کننده.

## پیشنهاد محصول (برچسب: پیشنهاد)

- RFQ ما همان ۴ گام + یک گیت انطباق (وضعیت کالا/مقصد) قبل از تطبیق — تمایز با MIC.
- مقایسه پیشنهادها به‌صورت جدول سند‌محور (قیمت/Incoterm/زمان/مجوز) نه فقط پیام.
