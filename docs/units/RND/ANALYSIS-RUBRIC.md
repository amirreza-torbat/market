# روبریک تحلیل رقبا — از ریز تا کلان

هر کالبدشکافی سایت باید این ابعاد را پر کند مگر بریف صریحاً زیرمجموعه بدهد.  
بخش بدون حداقل ۳ واقعیت قابل راستی‌آزمایی = خالی = رد QA (`M-DIM`).

کدها را در گزارش به‌صورت عنوان `## D12 — درخت دسته` بیاورید.

---

## لایه ۰ — هویت

| کد | بُعد | حداقل شاهد |
| --- | --- | --- |
| `D00` | نام، دامنه، مالک/شرکت مادر، سال، دفتر | درباره ما / ویکی شرکت / صفحه رسمی |
| `D01` | یک‌جمله ارزش پیشنهادی و مخاطب (خریدار/فروشنده) | هیرو خانه، عنوان تب |
| `D02` | افقی یا عمودی؛ جغرافیا؛ دسته غالب | منو، انتخاب کشور |
| `D03` | مدل درآمد آشکار | صفحه عضویت، تبلیغات، کارمزد |

## قاعده عمق

برای `D10`–`D29` حدس ممنوع است. اگر ندیدید بنویسید `مشاهده نشد` + علت.  
برای `D50`–`D56` منبع می‌تواند صفحه رسمی خدمت باشد نه فقط خانه.
