# روبریک عمومی QA

کد نقص را در برگه رأی بنویسید. واحدها روبریک تخصصی اضافه دارند.

## بحرانی — C (هر کدام = رد فوری)

| کد | بند |
| --- | --- |
| `C-SCOPE` | خروجی بریف را جواب نداده یا دامنه را عوض کرده |
| `C-SOURCE` | ادعای کلیدی بدون منبع قابل‌بازگشت |
| `C-FALSE` | واقعیت نادرست یا ساختگی به‌عنوان حقیقت |
| `C-DUP` | کار `done` قبلی را بدون ارزش جدید تکرار کرده |
| `C-ILLEGAL` | راهکار غیرقانونی یا دور زدن تحریم/گمرک |
| `C-MIX` | واقعیت و فرض قاطی شده و قابل جداسازی نیست |
| `C-PATH` | فایل در مسیر ابلاغ‌شده نیست |
| `C-SELF` | خودآزمایی ته گزارش نیست |

## عمده — M (هر کدام = رد)

| کد | بند |
| --- | --- |
| `M-DIM` | یکی از ابعاد اجباری بریف خالی یا سطحی است |
| `M-MIN` | حداقل تعداد منبع / سایت / کشور رعایت نشده |
| `M-STRUCT` | قالب واحد رعایت نشده؛ مقایسه ناممکن است |
| `M-HAND` | بسته اثر روی واحدهای دیگر نیست |
| `M-CONTRA` | تناقض با گزارش accepted همان واحد |
| `M-EVID` | قضاوت کیفی بدون شاهد (اسکرین، نقل قول، URL بخش) |
| `M-NEXT` | مجهولات و کار بعدی مشخص نیست |

## جزئی — m

| کد | بند |
| --- | --- |
| `m-typo` | غلط واضح |
| `m-link` | لینک فرعی شکسته |
| `m-order` | ترتیب بخش‌ها |
| `m-lang` | آمیختگی بی‌دلیل زبان |

## شدت سطحی‌بودن

اگر بخشی عنوان دارد ولی محتوایش کمتر از ۳ واقعیت قابل راستی‌آزمایی است، آن بخش **خالی** حساب می‌شود (`M-DIM`) نه «رفته‌شده».
