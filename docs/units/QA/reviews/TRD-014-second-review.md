# داوری دوم — TRD-014 (r1)

- داور دوم: «زیرعامل مستقل — نشست 2026-09-27 (مستقل از مؤلف و داور r1)»
- تاریخ: 2026-09-27
- رأی قبلی: pass مشروط (self-check-pending-second-reviewer)
- **حکم داوری دوم: pass با ملاحظه**

## پیوستگی (تطبیق فیلدها با TRD-004/005/013 — نمونه‌های مستقل از خودآزمایی مؤلف)

- بخش الف: «HS ۸ رقمی»، «مقدار/واحد/وزن ناخالص-خالص»، «ارز فاکتور + ارزش»، «فهرست پیوست‌ها» ← TRD-004 گام ۳/۲/۴ دقیق ✓؛ «وضعیت کالا سه‌وضعیت» ← TRD-004 T02 (اصل TRD-002 ماده ۲) ✓؛ «اعتبار کارت بازرگانی» ← TRD-004 T01 ✓.
- بخش ب: ساختار شناسه مجوز «{نوع، نهاد، شماره، تاریخ اعتبار}» عیناً همان TRD-005 (بخش اتصال) است؛ INSO (زعفران)، بهداشت نباتی (پسته)، IRC + اداره کل تجهیزات پزشکی، میراث فرهنگی (فرش دستباف بالای سقف) ← ماتریس و بندهای تفکیکی TRD-005 ✓؛ فیلد «تاریخ آخرین بازنگری ماتریس + منبع هر حکم» عیناً اجرای دستور T14-TRD-005 به TRD-014 ✓ (ردیابی‌پذیری درست).
- بخش ج: گیت (مسدود/compliance_hold/کانال‌محور) ← ستون گیت TRD-013 ✓؛ attestation (عراق/عمان؛ ترکیه حسب مورد) ← TRD-007/009/008 ✓؛ فهرست گواهی انطباق (ICIGI/CE-TSE/EAC/BIS/CCC+GACC+GB 7718) ← T08 همان پرونده‌ها ✓؛ فرم EAEU ← TRD-010 T05 ✓؛ صف بازرگان ← TRD-008 T12 ✓.
- فیلد «تولیدکننده یا بازرگانی (تفکیک) | RND-004 D40» کنترل شد: D40-TRD-004 تفکیک نشان Manufacturer/Supplier (الگوی GS) را ثبت کرده — ارجاع معتبر ✓.
- قانون تجمیعی (مسدودی فیلد اجباری خالی، غیرقابل انتخاب شدن امارات، هشدار به‌جای مسدودی برای مقصد-محور) ← TRD-004/006/013 بدون توصیه دور زدن گیت ✓.

## راستی‌آزمایی

- سنتز داخلی — بدون وب؛ کنترل ارجاع‌ها: ۸ فیلد نمونه از چهار بخش + قانون تجمیعی با مبدأهای accepted تطبیق داده شد. مرز نقش («تصمیم نهایی با PM/PIM») حفظ شده.

## ملاحظات/نقص جدید (جزئی — مغایرت ماهوی نیست)

- فیلد «کشور مبدأ + استان/شهر مبدأ | TRD-004 گام۲» ارجاع سست است: گام ۲ اظهار «کشور مقصد» و «محل خروج» دارد، نه مبدأ/استان محصول؛ «استان/شهر مبدأ» متادیتای محصول (PIM/RND) است. در ویرایش بعد منبع تفکیک شود (کشور مبدأ از مسیر COO/اظهار؛ استان/شهر مبدأ = متادیتای PIM).
- فیلد «برچسب زبان مقصد (عربی/ترکی/چینی GB 7718/روسی)» منبع «TRD-007/008/012» را ذکر کرده اما بخش «روسی» از TRD-010 T08 می‌آید — TRD-010 به فهرست منبع همان فیلد اضافه شود.

## نتیجه

رأی pass r1 با دو ملاحظه جزئی بالا تأیید شد؛ هر دو اصلاح صرفاً در حاشیه/منبع فیلد است و ساختار چک‌لیست را تغییر نمی‌دهد. برچسب pending-second-reviewer برای TRD-014 مرتفع می‌شود (SECOND-REVIEW-LOG).
