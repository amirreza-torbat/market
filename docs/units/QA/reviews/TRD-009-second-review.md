# داوری دوم — TRD-009 (r1)

- داور دوم: «زیرعامل مستقل — نشست 2026-09-27 (مستقل از مؤلف و داور r1)»
- تاریخ: 2026-09-27
- رأی قبلی: pass مشروط (self-check-pending-second-reviewer)
- **حکم داوری دوم: pass تأیید شد**

## پیوستگی

- الگوی T00–T14 مثل TRD-006..008؛ بازاستفاده از TRD-002/003/004 صحیح؛ تمایز سه‌گانه (عراق: ICIGI / ترکیه: CE-هم‌راستا / عمان: بدون برنامه سراسری) صریح و سازگار با پرونده‌های قبلی است.
- برچسب‌ها: تعرفه یکپارچه GCC از 2025-01-01 و مسیر شناور سریع‌السیر (۱۸۰+ کیلومتر) `سرنخ`؛ تعرفه ۵٪ GCC و VAT ۵٪ (۲۰۲۱) `واقعیت-دستورالعمل` — آمار بدون برچسب یافت نشد.
- گیت پرداخت (کم‌ریسک‌تر از امارات/ترکیه ولی مشمول ریسک ثالث، `سرنخ`) با قاعده compliance_hold بدون توصیه کانال موازی — سازگار با TRD-006/008 و C-ILLEGAL پاک.

## راستی‌آزمایی زنده

- ادعا (لنگر T00): گمرک عمان (ROP Customs) سامانه یکپارچه الکترونیکی «Bayan» با ورود PKI برای واحدهای تجاری.
- نتیجه: تأیید شد — درگاه رسمی customs.gov.om (صفحه Electronic Single Window) صراحتاً اعلام می‌کند واحدهای تجاری با PKI credential/Login به Bayan دسترسی دارند؛ منابع فرعی متعدد هم Bayan را تک‌پنجره‌ای اظهار/ترخیص/بازپرداخت ROP Customs توصیف می‌کنند.
- URL: https://www.customs.gov.om/esw
