# خانه واحدها — ورود سریع ایجنت

هر واحد پوشهٔ جدا دارد. ایجنت فقط وارد پوشهٔ خودش می‌شود.

| کد | پوشه | نقش | پرامپت |
| --- | --- | --- |
| `MGT` | [`MGT/`](MGT/README.md) | مدیریت: ابلاغ + توزیع بسته RND | [`../agents/01-MGT.md`](../agents/01-MGT.md) |
| `QA` | [`QA/`](QA/README.md) | کنترل کیفیت خروجی | [`../agents/02-QA.md`](../agents/02-QA.md) |
| `RND` | [`RND/`](RND/README.md) | تحقیق رقبا | [`../agents/03-RND.md`](../agents/03-RND.md) |
| `TRADE` | [`TRADE/`](TRADE/README.md) | بازرگانی بین‌الملل | [`../agents/04-TRADE.md`](../agents/04-TRADE.md) |

واحدهای قبلی (`LEG`, `FIN`, `SEO`, ...) هنوز در `docs/ORGANIZATION.md` تعریف‌اند. خانهٔ عملیاتی موج بعد برایشان ساخته می‌شود. تا آن روز تسک نمی‌گیرند مگر `MGT` ابلاغ کند.

## قانون سه‌واحدی کار

```text
MGT تسک را یکی‌یکی ابلاغ می‌کند
    → واحد تخصصی اجرا می‌کند
        → QA رد یا قبول می‌کند
            → اگر رد: همان تسک برمی‌گردد (حلقه کیفیت)
            → اگر قبول: MGT تسک بعدی را باز می‌کند
```

هیچ ایجنتی حق ندارد تسک بعدی را خودش باز کند.

## قبل از هر کار

1. `docs/STATUS.md`
2. `README.md` واحد خودتان
3. `ACTIVITY-LOG.md` واحد — تا کار تکراری نکنید
4. `CURRENT.md` — فقط همین فایل کار امروز است
