# بسته FIN-002 → INS

## وابستگی‌های بیمه‌ای ماشین
| وضعیت | وابستگی | نوع |
| --- | --- | --- |
| SHIP | بیمه‌نامه حمل (ذی‌نفع طبق Incoterms) — پیش‌نیاز DELIVERY برای کالای مشمول | INS-001 |
| DELIVERY | فعال‌سازی مطالبه بیمه حمل در خسارت؛ سند برای DISPUTE | INS-001 |
| ACCEPT | برای مدل معوق (M04/M08): بیمه اعتبار صادراتی (صندوق ضمانت صادرات) | FIN-001 M12 |
| INSPECT | بیمه مسئولیت بازرس — **داده در دسترس نبود** | باز |
| REFUND/RESOLUTION | subrogation؛ هماهنگی با بیمه‌گر پیش از تسویه | — |

## درخواست
1. مشخص‌کردن Minimum Cover (بیمه‌نامه حمل) برای دسته‌های مشمول.
2. فرآیند «اظهار خسارت + گزارش ثالث» به‌عنوان شاهد DISPUTE.
3. قالب فیلد بیمه‌نامه در بسته اسناد SHIP.
4. نگاه به «بیمه اعتبار خریدار» (گشایش LC ۱۰۰٪) به‌عنوان پشتیبان معوقات.
