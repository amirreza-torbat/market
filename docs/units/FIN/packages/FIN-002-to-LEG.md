## موارد درخواستی
1. متن شرط «پذیرش ضمنی» و پنجره ۵ روز کاری (یا مقدار تصویب‌شده).
2. شرط داوری و آستانه «اختلاف ساده» (پیشنهاد FIN: مذاکره ۱۰ روز کاری؛ داوری ۳۰ روز).
3. بازبینی K3 (فسخ توافقی، هزینه اثبات‌شده) و K7 (انقضا بدون جریمه).
4. اظهارنظر درباره «حساب امانی ارزی» تحت دستورالعمل جاری.

## قید
هیچ بندی برای دور زدن تحریم/تعلیق امارات؛ مسیر تحریمی = فسخ با بازگشت کامل (بدون جریمه طرفین طبق قانون) — متن آن را شما می‌نویسید.
