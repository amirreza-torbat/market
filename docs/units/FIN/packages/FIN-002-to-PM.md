# بسته FIN-002 → PM

## نمای محصول
جریان وجه پلتفرم: AUTHORIZE → HOLD → VERIFY → INSPECT → SHIP → DELIVERY → ACCEPT → RELEASE؛ با شاخه‌های REFUND/DISPUTE/RESOLUTION/CANCELLED/EXPIRED. وجوه از HOLD تا پایان اختلاف در حساب امانی (امین = پلتفرم) قفل است.

| --- | --- | --- |

| پنجره پذیرش خریدار | ۵ روز کاری + پذیرش ضمنی | PM/LEG |

## هشدار محصول
مقصد امارات تا ابلاغ رسمی = مسدود (قید G2)؛ روش‌های PR (حواله غیررسمی و…) هرگز در UI ظاهر نشوند (قید G3). هیچ دکمه/لینک «کانال جایگزین» برای دور زدن تعریف نشود.
