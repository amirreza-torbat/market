## ۲) جریان‌های حیاتی (End-to-end)

1. **سفارش با escrow:** Order → Compliance Gate → Funds (FIN-002) → Production → INSP PSI → Shipping (LOG) → Delivery → Release → LedgerEvent؛
2. **RFQ مهمان‌پذیر:** مهمان → فرم ۴گام → گیت CMP → پخش به تأمین‌کنندگان واجد → مقایسه؛
3. **مسدودسازی مقصد:** DestinationRule.gate=blocked → مقصد در UI نمایش داده نمی‌شود (امارات — TRD-006).
