- ورودی (همه accepted): TRD-014 (چک‌لیست فیلد — ۴ گروه)، CAT-001 (فیلدهای ویژه ۶ دسته)، TRD-013 (متادیتای مقصد پارامتری)، TRD-005 (مجوزها)، FIN-003 (رویدادهای دفتر کل)، CMP-002 (گیت‌ها)، LEG-004 (حداقل‌سازی داده)، RND-008 (کارت کالا رقبا)
- اعلان: این «دیکشنری داده پیشنهادی» است؛ تصمیم نهایی اسکیما با ENG-001/PM است. هر فیلد: نوع/اجباری/منبع.

## ۱) موجودیت‌ها (Entities)

| موجودیت | شرح | روابط کلیدی |
|---|---|---|
| `Product` | کالای ثبت‌شده | ← Variant[]، Certificate[]، Seller |
| `Variant` | نسخه کالا (اندازه/درجه/بسته‌بندی/گرید) | ← Product؛ قیمت/موجود/HS خاص خود |
| `Certificate` | گواهی/مجوز با اعتبار | ← Product/Seller؛ نهاد، شماره، اعتبار از–تا (TRD-005) |
| `SellerProfile` | تأمین‌کننده + پرونده انطباق عمومی | ← Certificate[]؛ طبقه عضویت (LEG-003) |
| `DestinationRule` | متادیتای مقصد پارامتری | مقصد؛ اسناد/گواهی/واردکننده/گیت (TRD-013) |
| `Order` / `Shipment` / `FundsState` | از TRD-003 و FIN-002 | ← Product/Variants، DestinationRule، رویدادها |
| `LedgerEvent` | رویدادهای مالی append-only (FIN-003) | ← Order |
| `ComplianceRecord` | رکورد گیت CMP (CMP-001 حالت‌ها) | ← Order/Seller |

## ۲) دیکشنری فیلدهای محصول (از TRD-014 — خلاصه ساختاری)

| گروه | فیلدها (نوع/اجباری) |
|---|---|
| پایه | HS(8، اجباری)، شرح، مقدار+واحد، وزن خالص/ناخالص، ارز+ارزش، وضعیت کالا (سه‌وضعیت)، پیوست‌ها[] |
| مجوز (TRD-005) | شناسه مجوز {نوع، نهاد، شماره، اعتبار از–تا} — مشروط به دسته؛ + تاریخ بازنگری ماتریس |
| مقصد (TRD-013) | مقصد، وضعیت گیت، attestation؟، گواهی انطباق مقصد، واردکننده ثبت‌شده، برچسب زبان مقصد |
| ویژه دسته (CAT-001) | زعفران: رنگ‌توانی/درجه؛ پسته: رقم/سال؛ فرش: گره/میراث؛ پتروشیمی: گرید/آنالیز؛ قطعه: استاندارد/دوکاربرده؛ پزشکی: IRC/IMED |

## ۳) نسخه‌ها (Variants) — معیار پذیرش

- Variant رکورد مستقل با HS/قیمت/موجود/گواهی خاص خود؛ ارث‌بری از Product با override؛
- تغییر قلمرو: هر تغییر HS/مجوز = نسخه جدید نه بازنویسی؛ تاریخچه نسخه‌ها نگهداری می‌شود؛
- الگو: کارت کالای رقبا (RND-003/005 D25) نشان داد Variant/گواهی جدا نیاز واقعی بازار است.

## ۴) گواهی‌ها (Certificates) — معیار پذیرش

- ساختار {نوع، نهاد صادرکننده، شماره سریال، اعتبار از–تا، سند اسکن، وضعیت}؛
- الگوی سریال‌دار MIC (RND-003 D40) و چک‌لیست TrustSEAL (RND-005) — هر گواهی قابل‌راستی‌آزمایی؛
- گواهی منقضی → هشدار خودکار + پرچم CMP (CMP-001).

## ۵) HS — معیار پذیرش

- HS فیلد سطح Variant؛ اعتبارسنجی ۸رقمی؛ کد غلط = ریسک اظهار (TRD-004 گام ۳؛ TSC)؛
- HS به DestinationRule وصل است: همان کالا در مقاصد مختلف اسناد متفاوت دارد (TRD-013).

## ۶) نسخه‌بندی داده (Versioning) — معیار پذیرش

- همه موجودیت‌های حیاتی (Product/Certificate/DestinationRule) نسخه‌دار + audit trail (چه کسی/چه زمانی — پروتکل عمومی)؛
- ماتریس‌های مبدأ (TRD-005) و مقصد (TRD-013) با «تاریخ آخرین بازنگری + منبع» ذخیره می‌شوند (T14 همه پرونده‌ها)؛
- داده شخصی طبق LEG-004: حداقل‌سازی؛ داده کارت هرگز (فقط مرجع).

## ۷) اتصال‌ها

- FIN-003 LedgerEvent ← Order؛ CMP-002 ComplianceRecord ← Order/Seller؛ TRD-003 Shipment ← Order؛ SEO/PIM درخت دسته (CAT-001)؛ LOC: برچسب چندزبانه (RND-007b زبان‌ها).
