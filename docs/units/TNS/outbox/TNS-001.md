## ۱) تاکسونومی نشان‌ها (Badges — هر نشان = سند روش + دامنه + تاریخ)

| نشان | معیار (سنددار) | ضدالگوی ممنوع |
|---|---|---|
| «تأمین‌کننده تأییدشده» | احراز کامل SUP-001 + اثبات عملیاتی | نشان بی‌سند (TradeKey/ExportHub/ایرانی‌ها — RND-006/007b) |
| «گواهی‌دار» | Certificate معتبر با سریال (PIM-001) | ادعای گواهی بی‌سند |
| «حسابرسی‌شده» | گزارش بازرس/حسابرس ثالث سریال‌دار (الگوی MIC — RND-003 D40) | «تضمین سفارش» بی‌سند (ExportHub) |
| «صادرکننده فعال» | سابقه سفارش موفق پلتفرم | آمار بدون تاریخ/مبنا |

`قاعده`: هر نشان: معیار عمومی + سند + تاریخ اعتبار + مسیر لغو. هیچ نشان تبلیغاتی سندبی‌ران نشده در محصول نمایش داده نمی‌شود.

## ۲) امتیاز و نرخ (Ratings)

- امتیاز دوطرفه پس از معامله واقعی فقط (نه از مهمان‌ها)؛
- سنجه‌های عملکردی با برچسب: پاسخ‌دهی، زمان ارسال، نتیجه بازرسی، اختلاف (الگوی On-time Delivery — RND-003 D17)؛
- حذف نظرات جعلی: غربال الگو + notice-and-action (LEG-003)؛ کپی‌رایت مطابق LOC/IP (LEG-004).

## ۳) مدیریتی (Moderation)

- محتوا/آگهی: بررسی پیش از انتشار (SUP-001 مرحله ۸) +notice-and-action پس از انتشار؛
- تقلب: الگوهای CMP-001 (پوسته، پرداخت واسطه، ادعای بی‌سند) → حالت‌های pass/hold/reject/escalate؛
- هر تصمیم مدیریتی: رکورد + دلیل + حق اعتراض (LEG-003).

## ۴) چرخه اختلاف (Escalation — تست‌پذیر)

```
ادعا (LEG-002 قالب) → تیکت CS-001 هم‌شناسه → مستندات دوطرفه
→ بازرسی/کارشناسی (INSP) → حکم: توافق/داوری (LEG-002) → اجرا در FIN-002 (حالت ۷-۹)
→ ثبت امتیاز/اقدام روی طرف متخلف
```
- هر گام ورودی/خروجی/SLA مشخص دارد → قابل تست خودکار است (معیار پذیرش).
- `اثر-محصول`: وضعیت‌های اختلاف در پنل دو طرف؛ هیچ حکم پنهانی نیست.

## ۵) T14

الگوهای تقلب جدید؛ تغییر قواعد نشان‌ها (تصمیم PM/وکیل)؛ یافته CS/DATA.
