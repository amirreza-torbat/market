## ۱) وایرفریم صفحات کلیدی (Wireframes)

| صفحه | بلوک‌ها (بر پایه الگوهای مشاهده‌شده رقبا) |
|---|---|
| خانه | جست‌وجوی مرکزی + درخت دسته (CAT-001) + دسته‌های شاخص + اعتماد |
| نتایج/لیست | کارت کالا (تصویر/قیمت دو-ارزی/MOQ/نشان سنددار/گواهی با تاریخ) + فیلترها (TRD-014) + صفحه‌بندی |
| PDP | گالری، مشخصات PIM-001، گواهی‌های سریال‌دار، جدول مقایسه Incoterm/زمان، CTA استعلام (مهمان‌پذیر) |
| پروفایل تأمین‌کننده | تب‌ها + پرونده انطباق عمومی + سنجه‌های سنددار (RND-003 D27 الگو) |
| RFQ | فرم ۴گام (RND-003 D32) + گیت انطباق شفاف |
| سفارش/پنل | نوار وضعیت دوگانه: حمل (TRD-003) + پول (FIN-002) + اسناد (TRD-014) |
| اختلاف | فرم ادعا (LEG-002) + ردیابی TNS-001 |

## ۲) قواعد کامپوننت (Component rules)

- هر کامپوننت: حالت‌های default/hover/disabled/loading/error/empty — **States**؛
- فرم‌ها: خطا کنار فیلد + متنی (دسترس‌پذیری UX-001)؛ دکمه اصلی یکی در هر نما؛
- اعداد: همیشه با واحد/ارز/تاریخ (قانون داده پروتکل)؛
- جدول‌ها: RTL/LTR آینه‌ای (LOC-001)؛

## ۳) خطاها (Errors)

پیام خطا سه‌لایه: چه شد (ساده) + چرا (دلیل فنی خلاصه) + چه کنم (اقدام). خطاهای گیت CMP: «توقف» شفاف با مسیر رفع — نه پیام مبهم (درس TRD-004).

## ۴) اسناد (Documents)

نمایش اسناد: نام/نوع/نهاد/تاریخ اعتبار + آیکن وضعیت؛ دانلود با دسترسی‌کنترل (TRD-014؛ LEG-004)؛ چک‌لیست پیوست پیش از اعزام (TRD-004 گام ۴) به‌صورت کامپوننت reusable.

## ۵) نشانه‌های اعتماد (Trust cues)

- نشان‌ها فقط با سند روش (TNS-001 تاکسونومی) + tooltip معیار؛
- گواهی با تاریخ اعتبار و سریال قابل‌کلیک؛
- امتیاز با برچسب عملکردی (الگوی On-time Delivery — RND-003 D17)؛
- ممنوع: نشان تبلیغاتی بی‌سند (ضدالگوی RND-009-۱).

## ۶) پالت/تایپ (شروع خنثی)

پالت خنثی + رنگ وضعیت (موفق/هشدار/خطا/گیت)؛ تایپ دو-اسکریپتی (لاتین + فارسی/عربی مخصوص)؛ hex نهایی در فاز طراحی بصری (مشاهدات متنی رقبا برای پالت کافی نبود — RND-003 D10 مشاهده نشد؛ مستند صادقانه).
