# LOG-001 — بریف شریک/ماژول لجستیک (باربری و رهگیری)

## ۱) جریان استعلام کرایه (Quote flow)

```
سفارش آماده حمل (TRD-003 حالت حمل داخلی) → درخواست استعلام (مبدأ/مقصد/وزن/حجم/Incoterm/مقصد نهایی)
→ دریافت پیشنهاد از N حمل‌کننده/فورواردر → مقایسه (قیمت/زمان/سابقه/بیمه INS-001)
→ انتخاب + قرارداد حمل (LEG-002) → رزرو
```
`اثر-محصول`: ماژول استعلام با فیلدهای استاندارد؛ ذخیره پیشنهادها برای مقایسه (الگوی مقایسه RFQ — RND-003 D32).

## ۲) رهگیری (Tracking states — اتصال TRD-003)

- هر رویداد حمل‌کننده به حالت سفارش map می‌شود: بارگیری داخلی → ورود مرز/بندر → حمل اصلی → ترانزیت → ترخیص مقصد → تحویل؛
- استثناها: توقف گمرکی (customs_hold)، آسیب (damaged)، تأخیر (delayed) — همان ۵ استثنای TRD-003؛
- `اثر-محصول`: وضعیت حمل زنده در پنل دو طرف؛ هیچ وعده زمان قطعی (درس TRD-004/008).

## ۳) بسته‌بندی (Packing)

- الزامات: مطابق نوع کالا/مقصد؛ پکینگ‌لیست دقیق (TRD-004 پیوست)؛ برچسب‌گذاری مقصد (TRD-007..012 T08: عربی/ترکی/چینی GB 7718)؛ نشانه‌های حمل استاندارد؛
- `اثر-محصول`: چک‌لیست بسته‌بندی پیش از اعزام (اتصال چک‌لیست مقصد TRD-004).

## ۴) دست‌به‌دشدها (Incoterm handoffs — TRD-003)

| Incoterm | نقطه تحویل حمل‌کننده | سند |
|---|---|---|
| EXW | تحویل در محل فروشنده | رسید تحویل |
| FCA | تحویل به حمل‌کننده (ترمینال/مرز) | CMR/CTO |
| FOB/CIF/CFR | روی عرشه بندر مبدأ | B/L |
| CPT/CIP/DAP | تحویل به متصدی/مقصد | CMR/B/L + بارنامه مادر |

## ۵) کریدورهای ایران (از پرونده‌های کشور)

| مسیر | مقاصد | یادداشت |
|---|---|---|
| زمینی غرب (بازرگان/خسروی/پرویزخان/باشمق) | ترکیه/اروپا | صف بازرگان — TRD-008 T12 |
| زمینی جنوب (مهران/شلمچه/چذابه) | عراق | وضعیت مرز متغیر — TRD-007 |
| ریلی شمال (رازی/آستارا؛ رشت–آستارا در ساخت) | روسیه/اوراسیا | TRD-010 T06 |
| دریایی جنوب (شهید رجایی) | خلیج فارس (عمان/امارات-مسدود)، هند، چین | TRD-009/011/012 |

## ۶) T14

نرخ‌نامه‌ها (استعلام دوره‌ای)؛ وضعیت مرزها (TRD-007/008)؛ تکمیل رشت–آستارا؛ تحریم حمل‌کننده‌ها (پرچم CMP — انتخاب حمل‌کننده هم گیت CMP-001 گروه د دارد).
