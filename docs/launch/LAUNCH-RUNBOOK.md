3. **Migrations:** `npx prisma migrate deploy` (فایل‌های 0001/0002/0003 آماده‌اند)
4. **Seed:** دسته‌های CAT-001 + مقاصد RU/TR/OM/IQ + AE-blocked
5. **SoD لانچ:** کاربر ADMIN واقعی + کاربر CMP جدا (دو-کلید برای آزادسازی وجوه — SEC-001)
