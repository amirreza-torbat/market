# بازار B2B صادراتی ایران

این مخزن، **سند مادر تحقیق، طراحی و راهبری ایجنت‌ها** برای ساخت یک بازارگاه B2B صادراتی است؛ نه کپی ساده‌ای از Alibaba. در این مرحله تمرکز روی کشف بازار، تحلیل رقبا، مسیرهای واقعی خریدار و تأمین‌کننده، ریسک حقوقی/مالی و تبدیل یافته‌ها به بسته‌های قابل‌پیاده‌سازی است.

## اصل اجرایی

مدیر (`MGT`) تسک‌ها را **یکی‌پس‌ازیکی** ابلاغ می‌کند، ایجنت متخصص گزارش مستند و بسته تحویل می‌دهد، و `QA` مستقل آن را می‌پذیرد یا برمی‌گرداند. هیچ گزارش پژوهشی مستقیماً وارد کدنویسی نمی‌شود؛ `PM` آن را به نیازمندی، `ENG` آن را به طراحی فنی، و سپس تیم محصول آن را به پیاده‌سازی تبدیل می‌کند.

> وضعیت فعلی این شاخه، مبنای کار همین مخزن است. لینک‌ها و کدهای شاخه‌های دیگر صرفاً سابقه پژوهشی منبع‌اند.
